# Clara y Guillermo · Menuda fiesta

Web estática para la boda del 24 de octubre de 2026 en Avilés. Incluye 44 fotos y 14 vídeos optimizados, galería con filtros y visor, y un enlace de Dropbox para recibir contenido de los invitados.

## Publicación

No requiere instalación ni compilación. Sube el contenido de este repositorio al directorio del alojamiento, dejando `index.html` directamente en la raíz de destino y conservando la carpeta `assets`.

El botón «Sube las tuyas» abre la solicitud de archivos de Dropbox. Las nuevas aportaciones se recogen en Dropbox y deben añadirse a la galería posteriormente.

`descargar.html` permite preparar un ZIP de la web desde el navegador.
